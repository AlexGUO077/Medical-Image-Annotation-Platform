## 范围与阶段边界

源 Word §9.1 的 M2 是任务分发、标注工作台、提交与状态机、帧服务和水印，验收为 X 线与 CT 各一例从待分配到待审核，以及 §8.4 防下载前五项。云端部署、完整审核台、发布/下线、检索与自查表全项属于 M3；纠正此前 STATUS 把生产部署当成 M2 必需开发阻塞的表述。依据需求基线 WP-06～WP-10、S5～S8、SG-4。

本批补齐手册 §6.2 的附件预览和拖拽调窗：附件仅以水印分页 PNG 返回，实时校验本人有效标注分派、合成来源与脱敏确认，存储读取后再次鉴权，审计失败不返回图片；临时 Blob URL 在关闭/切页/卸载时撤销。拖拽调窗松手后申请既有安全帧，绘图工具与调窗互斥。没有新增数据库表、迁移、业务额度或默认期限。手册未定义任务归档流程，当前也没有归档接口；将来引入时必须闭环残留 active 分派，不将此未来要求追加入 M2。
