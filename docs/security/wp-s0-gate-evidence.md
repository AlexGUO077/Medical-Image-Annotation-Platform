## 3. 安全测试基线

- 认证/授权：校验顺序、会话立即失效、横向/纵向越权、管理员不自动获得业务权限、来源授权过期/撤回、双人审批职责分离。
- 导入/去标识化：zip bomb、路径穿越、符号链接、类型伪装、恶意附件；DICOM 标签/像素/overlay/私有标签/UID/日期处理及人工复核。
- 防下载：页面无下载/打印，抓包只有 `/api/frames/{token}` 渲染帧；过期、换账号/会话或篡改帧参数为 403；高速翻帧为 429 并锁定。
- 基础设施：Orthanc、MinIO、Elasticsearch、PostgreSQL、Redis 无公网入口；秘密外置；TLS、安全头、备份加密和恢复验证。
- 审计/事件：帧、标注、审核、发布、导出、权限/授权变更均可查；审计故障时高风险操作失败关闭；规定场景完成演练。
- 发布扫描：SAST、依赖/许可证、秘密、镜像、IaC、DAST/渗透测试；严重和高危问题关闭或按规则阻断，不擅自添加例外。

当前仅有 WP-00 的 CI/扫描历史，不能替代上述业务与安全实证。

## 4. 当前门禁结论

- SG-0：未放行。未取得责任主体、处理目的/合法基础、完整授权、PIPL 影响评估批准、正式分类分级和等保适用性结论。
- SG-1：未放行。数据流、权限和威胁缓解已有可评审草案，但 D-30～D-37 批准与生产责任分工未完成。
- 允许范围：继续维护工程骨架和合成/不可逆匿名测试环境。
- 禁止范围：真实数据连接/导入、生产秘密、对外开放、发布或导出真实数据；在 WP-S0 未放行前启动依赖它的 WP-01～WP-17。
