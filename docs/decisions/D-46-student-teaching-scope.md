# D-46 学生考核与教学范围扩展

状态：2026-10-26 需求讨论；2026-10-27 用户明确要求“在新的本地分支上按手册和仓库规则开发这一功能”，按手册推荐的最小方案实施。验证与完成状态见 docs/STATUS.md；本决定不代替安全门或人工验收。

## 来源

用户本轮要求新增学生身份、考核式标注、部位/器官选择、学生报告、参考对照与评价，以及预录学生身份、自设密码和可用测试账号。原 Word §1.4/§2.2 的本期边界不覆盖该功能，需要记录新增范围，不能将原生产标注协议直接套用于学生。

## 已明确

- 新增学生教学入口，作答时不提供已有报告及详细病例资料，复用并修改现有标注工作台布局。
- 用户答复：“2和评分还有针对性反馈”，对应提交后查看教学版标准答案。
- 用户随后明确：“报告是随标注病例自带就有的 系统暂时只需要仅需要展示 但不排除后续需要平台能够分析学生回答与标准答案的区别给出针对性建议与复盘的功能”。据此第一版不要求自动分析自由文本报告，先展示现有参考；自动差异建议与复盘后续考虑。
- 用户最新答复：“第一版全部先做对照展示，不自动评分”。因此首版不做客观项或自由文本自动评分，评分和智能反馈统一后置。
- 2026-11-12 用户确认所有学生题均有病灶，须支持独立标注多个对象，并在交卷后对照病例自带的医生所见与诊断意见。
- 开发交付提供可登录的学生测试账号。

## 本次授权下采用的首版方案

以下为依照手册推荐值作出的工程实施选择，不追述为用户此前逐项确认：

- 现有管理员维护学生名册、安排考核和查看答卷；首版不新增教师身份。
- 学号在本平台唯一，并作为登录名；管理员预录姓名、班级、有效期，单独交接7天有效的一次性激活码。学生设置密码；已激活账号使用既有改密入口。首版未提供忘记密码重置。
- 一次考核可包含最多50病例，每例包含其获准序列；每名学生每题一次提交。管理员可结束/撤销考核；无默认计时器。
- 身体部位采用现有全部二级字典；对象器官/位置先使用文字，独立填写所见和诊断意见。每例至少提交一个病灶，多个病灶各有独立几何、器官和描述。空对象仅可存草稿。
- 管理员发布时核对病灶与脱敏报告，从原文分别摘取所见和诊断意见；交卷后按项目与学生原稿对照。历史题保留冻结全文；病例有已确认金标准时提供冻结轮廓叠加。详细临床、原始附件及生产病例库始终不向学生开放。
- 演示账号使用纯合成DX/CT题目，保留 student_demo 未提交供用户使用。老师样例不自动变成考题，管理员按已有来源边界选择。
- 同一React应用独立学生路由；学生答卷与病例生产任务、版本、状态分开。首版不评分，亦不创建评分或模型服务。

## 后续需求

教师管理范围、独立器官字典、重复练习/计时、忘记密码重置、报告差异分析和自动评分可按实际使用再扩展。以上不是阻断当前首版的待批准事项。
