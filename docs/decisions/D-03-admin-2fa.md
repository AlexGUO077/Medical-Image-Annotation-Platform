# D-03 管理员双因素认证

## 状态

已批准，2026-09-20 生效。

## 决策

- 管理员使用兼容 Microsoft Authenticator 的 TOTP；普通业务人员不强制启用 2FA。
- 管理员每次登录均在密码验证后完成 TOTP 验证，成功后才签发 8 小时正式 JWT。
- 首次登录先强制修改初始密码，再完成 TOTP 绑定。绑定和登录挑战只签发 5 分钟、用途受限的临时 JWT，不能访问业务接口。
- TOTP 密钥加密存储；同一动态码在有效时间窗内不得重复使用。复用现有 Redis 实现防重放和失败限流，不新增服务。
- 当前只在管理员登录时强制 2FA，不增加敏感操作二次挑战或独立近期认证系统。
- 不建设自助恢复平台。由另一名已完成 2FA 的管理员执行重置并写审计；单管理员紧急情况使用仅限本地的管理命令。
- 不新增业务表；在 `users` 增加 `must_change_password` 和 `mfa_secret_encrypted` 两个实现手册行为所必需的字段。

## 边界

- 不接入短信、邮件或第三方身份平台。
- TOTP 明文密钥、密码、JWT 和完整二维码内容不得进入日志、Git 或审计详情。
- 浏览器仅在运行内存保存正式 JWT；刷新或关闭页面后重新登录。
- 会话失效复用 `users.updated_at`：JWT 携带签发时的精确值，账号停用、到期、改密或资格变更后不再匹配；不增加 refresh token、token 黑名单或独立会话平台。

## 回滚

回退认证代码，并执行本工作包新增 migration 的 `down` 删除两个字段；不得修改已合并的 WP-01 migrations。
