# WP-04 导入与脱敏最小决策

## 状态

已批准，2026-09-21 生效。实现仍须经过郝鹏翼老师的脱敏改动组长复核后方可合并。

## D-04 脱敏映射存储

- 不新增第 17 张业务表。`reports.mask_map_id` 保存一个 UUID，以该 UUID 定位 MinIO 私有桶中的映射对象。
- 映射对象只保存“原姓名及其替换位置”所需的最小 JSON，使用独立环境变量 `MASK_MAP_ENCRYPTION_KEY` 进行 AES-256-GCM 加密；密钥不得复用 JWT、帧 token 或对象存储密码。
- 普通业务接口、日志、错误响应和 Elasticsearch 均不得返回映射。仅管理员可按单个病例审计读取，读取操作写入 `audit_logs`；不提供列表浏览、批量读取或导出。
- 映射随对应报告管理。合成数据阶段按已批准 D-30 由项目负责人按需手工清理，不建设自动保留与删除平台；真实数据接入前重新确认期限和密钥方案。

## D-15 导入压缩包结构

- 只接受 ZIP。一个顶层目录代表一个病例；顶层目录内可递归放置 `.dcm`，病例目录根部最多一个 UTF-8 `report.txt`。
- 单病例 ZIP 可直接把 `.dcm` 和可选的 `report.txt` 放在压缩包根部。不得同时混用根部病例文件和多病例顶层目录。
- 每个病例目录只允许一个 `StudyInstanceUID`；出现多个 Study、报告重复或目录无法匹配时，仅该病例失败，不中断同批其他病例。
- 禁止嵌套压缩包、符号链接、绝对路径、路径穿越和规范化后重名。除 `.dcm` 与 `report.txt` 外的文件按恶意或不支持附件处理，该病例失败。
- 合成数据阶段默认上限为：压缩包 512 MiB、解压后 2 GiB、5000 个文件、总压缩比 100:1。达到任一上限即拒绝该批次，真实数据阶段按实际模态重新评审。

## D-17 OCR

- 使用本地 PaddleOCR 中文模型，覆盖中文、英文和数字；不调用外部云端 OCR。
- 仅检查每个序列首帧。置信度不低于 0.80 且命中姓名或患者 ID 规则时，病例进入人工确认；OCR 执行失败也不得自动放行。
- 人工确认只展示去标识化后的带水印首帧、命中文本和位置，不展示原始 DICOM、原始标签或下载入口。确认前病例不得进入待分配状态。

## D-18 NER 集成

部署兼容依赖和最小打包补丁由已批准 [D-44](D-44-worker-container-security-compatibility.md)约束；UIE-mini、中文 PP-OCRv3、单个本地子进程和以下处理规则不变。

- 使用 PaddleNLP UIE，与 PaddleOCR 共用一个本地 Python 子进程；不新增 HTTP 服务、端口、数据库或独立平台。
- NestJS 负责队列、权限、状态和持久化，通过固定的 JSON 标准输入输出协议调用子进程。原始文本不得离开本机进程边界，不得写入日志。
- NER 命中与称谓正则命中取并集，姓名替换为“某”，年龄数字保留；替换前后的最小映射按 D-04 加密保存。
- 子进程不可用、输出无效或脱敏失败时，该病例留在隔离区并记录最小失败原因，不把原始报告写入正式数据库。

## 共同边界

- 当前只处理 D-31 明确批准的 `synthetic` 与 `teacher_provided_teaching`；老师提供样例仅限本项目开发测试，其他真实医学数据入口继续关闭。
- DICOM 去标识化继续执行已批准 D-37：Basic Application Level Confidentiality Profile、Clean Pixel Data、私有标签默认删除、UID 引用一致和首帧人工确认。
- 不新增审批流、KMS、保留删除编排、云端识别服务或通用机器学习平台。
- 该模块属于脱敏 HIGH 风险改动，实现完成后仍须郝鹏翼老师进行组长复核，不能以自审代替。
- 每个导入批次的 `source` 必须与已批准 D-31 的[数据来源与保留最小契约](../contracts/source-authorization-and-data-lifecycle.md)绑定。当前由服务端形成仅限合成数据开发的批次来源记录，并随批次元数据、病例和审计保存；不得把来源控制降为只校验一个非空字符串。
