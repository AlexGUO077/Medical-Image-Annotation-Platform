# D-43 合成环境部署与一致性备份

状态：待用户确认。依据源 Word §8.1～§8.3、WP-16、既有 D-30/D-34 最小边界；不新增平台、业务表或部署服务。

## 部署范围

建议首批完成仅 synthetic 的隔离部署包及本地 HTTPS/恢复演练。保持源手册七个运行服务，仅 nginx 暴露入口；沿用现有中间件补丁镜像、Node 24、Python 本地子进程。Let's Encrypt/certbot 签发和续期按手册实施，真实签发需要部署域名、服务器及负责人的证书联系邮箱。域名/主机未提供时仅使用临时本地测试证书，不声称云端或可信证书验收通过。

不外传老师样例，不创建真实数据或生产连接。云端合成测试部署需给出具体目标；服务秘密通过目标环境私有文件/受控变量注入，不通过聊天、Git 或公开日志交接。

## 备份一致性缺口

源手册明确每日 PostgreSQL pg_dump 保留最近 30 份、Orthanc/MinIO 每日异地 rsync、每月临时环境恢复并打开 3 例，但未定义跨服务一致性和备份时停写方式。

建议最小方式：备份期间短暂停止 server、Orthanc、MinIO，等待停止成功后 pg_dump 与复制两个数据卷，结束恢复原运行状态；不用在线快照服务或增量平台。仅成功并校验的完整批次进入异地同步，失败不删旧备份；同步失败报告失败。成功 PostgreSQL 备份只保留最近 30 份；影像/对象备份不擅自定义自动删除期限。异地地址和定时窗口由部署负责人配置，不预填实际远端或自动安装定时任务。

密钥/私有配置与备份介质分开保管。恢复只指向明确标识的隔离临时环境，不覆盖已有库/卷；恢复 PostgreSQL、Orthanc 与 MinIO 同批数据，Redis 票据不恢复，ES 从 PostgreSQL 发布数据对账重建。恢复验收验证至少 3 个合成病例的受控预览与对象可用性，不以文件存在替代“可打开”。

## 确认与边界

部署范围和停写方案确认前，继续不受影响的已有运行依赖核验和构建准备；不启动公网部署、异地传输或定时备份。代码/配置可评审不等于 SG-6、M3 或上线验收完成。
