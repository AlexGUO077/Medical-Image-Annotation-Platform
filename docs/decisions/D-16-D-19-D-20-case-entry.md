# WP-05 手工录入、附件预览与录入资格最小决策

状态：用户于 2026-09-23 批准。依据源开发手册 §4.2、§5.2、§6.3、§7.2 和需求基线 WP-05；接口细节见[病例录入与临床信息契约](../contracts/case-entry-api.md)。

## D-16 手工简版录入

- 只接收报告文本与一张 JPG/PNG 关键影像，来源必选且仍受 D-31 白名单约束。
- 关键影像作为病例附件保存；手工病例不创建虚构的 DICOM Study/Series，也不支持向该病例补充 DICOM。需要 DICOM 时重新走既有 ZIP 导入流程。
- 原始文本和影像先进入隔离暂存，按既有本地脱敏链处理。只向前端返回遮蔽后的报告和安全预览；处理失败或未经管理员显式确认，不进入正式病例与对象存储。

## D-19 附件安全预览

- JPG/PNG/PDF 提供有权限用户可见的只读水印预览；DOCX/XLSX 必须由服务端在隔离环境转换为只读预览格式后展示。
- 所有预览均经服务端鉴权、加账号／姓名／时间水印，使用 `no-store`，且不提供原始附件下载。转换失败时不返回原件或未加水印内容。
- 附件上传仍遵守 PDF/JPG/PNG/DOCX/XLSX 白名单、单文件不超过 50 MB、分片与脱敏确认要求；不因此增加独立转换服务或新的业务表。

## D-20 录入资格

- 当前版本仅管理员可导入、手工录入、编辑病例临床信息与教学字段、上传和确认附件；服务端逐接口鉴权，前端隐藏非管理员入口。
- 当前不新增 `quals` 中的“录入”枚举。以后开放给其他角色时，先单独确认资格值与授权范围。
