# D-26 合成病例浏览器草稿

2026-09-30 用户确认：采用合成数据最小方案。依据手册 §6.2 的操作后 2 秒自动保存、断网暂存和恢复要求，以及 UI §12 的串行保存与冲突阻断要求。

- 仅 synthetic 病例启用 IndexedDB 草稿，按账号 ID 和病例 ID 隔离；保存标注对象和基准版本，不保存影像、报告正文、帧票据或凭证。
- 本阶段使用浏览器本地存储，不新增密钥管理、加密服务或自行规定保留时限；此方案不放行真实数据。账号隔离是应用数据分区，不代表同源脚本或设备使用者无法访问浏览器存储。
- 每次有效编辑更新草稿；服务器保存确认后清理对应草稿，保存期间发生的新修改继续保留。显式登出清理该账号草稿，清理失败必须显示，不假报成功。
- 断网或会话失效不丢弃未保存内容。恢复网络或重新登录后，先通过现有受保护读取接口重新检查权限和当前版本，再决定能否保存。
- 基准版本不同则暂停自动保存，保留本地内容供比较；用户可采用服务器版本。V1 不自动合并同一对象的修改，不提供强制覆盖。
- 网络失败可能发生在服务器提交之后，恢复时仍先读取版本，不盲目重发。
