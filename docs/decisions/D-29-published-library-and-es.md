# D-29 已发布库与 ES 同步最小契约

状态：2026-10-06 待用户确认；未批准前不实施受影响的检索/帧授权、同步或页面逻辑。

依据：源 Word §2.2/§2.3/§3.1/§5.2/§6.2/§6.3/§9.4；需求基线 WP-12、§7.6、D-29；UI §15.4。手册要求系统资格下的只读已发布库、四级标签浏览、组合和全文检索、安全缩略图，以及发布/更新同步和每日全量对账，但未固定检索载荷、分词器及故障恢复策略。

## 待确认的业务与接口边界

1. 当前只开放 `synthetic` 已确认脱敏、已发布的当前金标准版本。对应系统具有 `annotate` 或 `review` 任一资格即可只读访问；管理员也须具备该资格，无管理员阅片旁路。非合成来源继续关闭本批检索授权，老师样例仍限既有隔离导入开发，不因本批公开。停用、资格撤销、下线、软删除和版本变化使详情/帧/附件访问即时失效。
2. `GET /api/search` 接受 `system_code`、`part_id`（二级标签）、`disease_id`（三级/四级疾病）、`sign_tag_id`、`modality`、`source`、`q`、`page`、`pageSize`。不同条件 AND；疾病节点包括其子分型，征象匹配当前金标准标注，模态匹配任一活跃序列。`q` 检索脱敏报告及临床文本，ES 内置 `standard` 分词，输入作为普通文本、不接受 DSL；不增加中文插件。无 `q` 时组合条件由 PostgreSQL 执行；有 `q` 时由 ES 匹配，并按 PostgreSQL 当前可见范围及内容版本限制命中。响应 `{items,page,pageSize,total}`；默认每页 20，最多 100。卡片返回病例号、系统、来源、模态、诊断、征象、当前版本和安全缩略图定位，不返回原始 ES 文档或存储/Orthanc 键。全文按相关性及稳定 ID 排序，无全文按最近更新及稳定 ID 排序。
3. 新增 `GET /api/library/:caseId` 与只读附件预览接口，返回脱敏临床/教学字段、报告句子、序列定位及当前金标准标注；复用既有帧票据、限流、水印、内存 loader 与只读轮廓显示。缩略图走同一安全帧服务；不新增导出/下载，库访问不授予编辑、普通审核或质量审核提交权限。

## 待确认的同步与失败处理

PostgreSQL 是事实来源。业务事务提交后异步请求同步病例，ES 故障不撤回已成功的发布/下线；失败在原后端进程内重试，启动时及每日全量对账修复缺失、过期、下线/删除和孤儿文档。无新表、队列或部署服务；使用现有 ES 容器和 Node 原生 HTTP，索引只保存匹配所需的合成脱敏文本和版本/过滤字段，不保存映射、附件路径、患者标识或像素。

ES 故障时全文检索明确返回 503，不伪装空结果；无全文的组合查询及已授权详情可继续由 PostgreSQL 服务。未同步的新增/更新可能暂不命中全文；已下线、删除或失效病例即使留有 ES 文档也被数据库事实拒绝，不能凭旧索引读取。索引映射版本升级时由管理员从 PG 重建，旧索引不能改变业务事实；不提供公众重建接口。

## 验证与本批执行顺序

确认后先固定 API mock 和索引/字段契约，再实现权限与查询、提交后同步及对账、只读库页面。无需新增业务字段的部分不制造空迁移；仅在实际发现必要数据库约束/索引缺口时先实现迁移，再接页面。

关键验证：跨系统/无资格/无管理员旁路；未发布、未确认脱敏、其他来源及软删除拒绝；中文全文和四级子树/征象/模态组合；分页与总数仅含授权当前版本；发布、下线、质量打回、重启再发布、同步失败重试、进程恢复及孤儿清理；旧帧票据和附件拒绝；只读及登出/失效清屏；X 线/CT 发布后检索可见。使用合成 PostgreSQL、Redis、真实 ES 及浏览器验证；不以 mock 声称真实完整端到端链路或 SG-5 放行。
