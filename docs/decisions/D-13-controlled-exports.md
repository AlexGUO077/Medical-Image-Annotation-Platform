# D-13 管理员受控导出最小方案

状态：内容与时效/领取口径均于 2026-10-07 经用户明确确认。源 Word §2.2/§2.6/§4.5/§5.2/§6.3/§8.4 要求管理员申请、另一管理员审批后生成时效链接、全量审计，禁止原始 DICOM、整序列打包与批量导出影像；需求基线 WP-14/S10/SG-5、UI §15.6。按 AGENTS.md §2，以下内容和时效已确认，按最小范围实施合成测试；不推定 SG-5 或生产放行。

## 已确认的最小口径

1. **内容**：仅已确认脱敏、未软删除的 synthetic 当前发布且金标准锁定版本；单个 JSON 数据包，包含必要病例/来源/系统/版本标识、疾病/征象标签、金标准几何与报告句序号，以及几何定位所需的序列逻辑标识/尺寸/标定/窗参数。排除影像（含渲染帧）、DICOM/UID、报告或临床正文、附件、映射、账号实名/IP/存储键。老师教学样例和其他真实来源不开放导出。
2. **时效及失效**：批准时固定申请中所选病例版本；链接有效 24 小时，最多领取一次，仅申请管理员凭当前有效 access 会话访问，不使用匿名 MinIO 链接。批准及领取时复核申请人/审批人可用且均为管理员、来源与当前病例仍发布/金标准/同版本；失权、下线、版本变化、软删除或到期均拒绝。读包失败不消耗领取次数，领取开始即原子占用一次机会，响应中断不自动补次数。批准失败不留下有效链接。
3. **操作与存储**：沿用已批准 D-03 登录 2FA，不增设操作二次挑战；提交申请及另一管理员批准/拒绝均二次确认。复用 export_requests、audit_logs 和 MinIO 私有桶；仅为申请人、申请版本清单、领取次数补充必要字段/约束，不新增表/服务/调度。申请、批准/拒绝、领取与拒绝领取留最小审计；列表/详情不返回秘密或私有存储键。不新增跨平台发送、匿名分享或影像下载。本期导出包到期即不可读，按已批准合成测试数据规则由负责人手工清理，不自建清理服务。

## 实施及验证范围

确认后先写接口契约与 mock，必要迁移先于页面。扩展 /admin 的申请/审批队列；后端事务防自批、并发审批/领取、审计失败回滚和对象补偿。DX/CT 合成病例验证 JSON 最小内容、来源/版本复核、时效与一次领取；成员、停用/过期/旧会话、不可自批及存储/审计失败均拒绝。不外传数据、不打开真实数据或生产导出；非作者评审、组长权限复核与 SG-5 人工验收继续独立记录。

审计查询和异常账号解锁可在此口径确认前按既有 D-03/D-24/D-25/D-34～D-36 继续准备；审计只读，复用数据库只增触发器/应用角色，不建设 WORM/哈希链或审计员系统。
