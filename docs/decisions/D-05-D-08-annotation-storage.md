# D-05～D-08 标注保存细节（已确认）

依据源手册 §4-9、§5.2/§5.3、§7.4/§7.5。用户于 2026-09-30 在本会话明确批准以下方案。

- D-05：采用同表多版本，不新增快照表。复用 annotation_objects 与 annotation_tags 按版本保存新行并保留旧行；cases 记录当前标注版本号以支持空版本；对象具有跨版本稳定标识，供打回对比。保存携带读取时版本号，过期请求返回冲突，防止覆盖其他保存。原快照表建议不实施。
- D-06：独立 key_frame_index 字段；单帧为 0，多帧在 frame_start/frame_end 范围内。
- D-07：part_id 引用 taxonomy_nodes 二级部位/类别，校验所属系统。
- D-08：复用 report_sent_ids 的保留值 [-1] 明确表示“报告未提及”，不新增 report_not_mentioned 字段；禁止 -1 与实际句号混用，[] 仍表示未关联。实际句号从 0 开始。

以上是手册未规定的存储细节选择，不增加业务配额、期限或审批流。保存草稿不等于通过提交完整性校验；报告关联和“报告未提及”的显式状态应在后续提交环节检查。
