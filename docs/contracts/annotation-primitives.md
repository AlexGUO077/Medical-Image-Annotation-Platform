# 标注基础逻辑（尚未接入标注界面）

依据源手册 §7.4、§7.5 与基线 WP-09/WP-10。本文件描述可独立验证的纯函数层，本层不新增公开接口、数据库字段或页面控件；存储决定见已批准的 D-05～D-08，保存与历史接口见 annotations-api.md；工具界面与提交校验仍待接入。

- 坐标：存储对象使用左上角为原点的原始 DICOM 像素坐标，保留小数精度。显示变换由原点和两个像素轴向量描述，支持缩放、平移、翻转和旋转；逆变换拒绝非有限数值或不可逆矩阵。矩形拖动在图像坐标中归一化；变换不修改对象本身。接入 Cornerstone 时须由实际视口投影取得轴向量，不把 CSS 缩放比或显示帧尺寸猜作原始像素尺寸，也不据此推断毫米测量。
- RLE：二值掩膜按行从左到右、从上到下展开，`rle` 是从背景 0 开始、前景 1 交替的行程长度数组；全背景为 `[width*height]`，全前景为 `[0,width*height]`。仅首个行程可为零，其余为正整数，总和必须等于像素数。每帧独立编解码。解码写入调用者提供的缓冲区，先完整校验再写入；不根据外部输入尺寸自行分配大数组。手册中“通常 <5KB”为体积参考，不作为保存上限。
- 报告候选：取征象名、可用同义词和部位名构成去重关键词集，以命中词数排序，句子 ID 保留导入时的 idx。命中仅发生在“未见/无/不除外/需与”前缀分句时，技术排序权重取 0.5，仍保留候选；同句其他分句的阳性命中不受其影响。候选提示不自动建立关联、不自动认定提交豁免，也不生成“报告未提及”。

这些规则尚未接入生产标注读写，不代表四工具、断网恢复、版本历史或提交校验已完成。
