## 仓库纪律

- `main` 只保存通过验证的稳定版本。
- 功能、修复、安全、文档和工作包均在独立分支完成，通过 Pull Request 合并。
- 每个有意义、可评审、可回滚的变更必须提交并推送到 GitHub；本地提交不作为阶段完成证据。
- 真实 DICOM、患者信息、原始报告、脱敏映射、数据库备份、密钥、Token 和 `.env` 严禁进入 Git。
